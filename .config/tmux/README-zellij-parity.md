# Deprecated tmux zellij-parity profile

This setup no longer uses a separate `zellij-parity.tmux.conf`.

- Canonical config: `~/.config/tmux/ghostty-parity.tmux.conf`
- Canonical launcher: `~/.local/bin/tmux-zellij-ghostty`
- Compatibility alias: `~/.local/bin/tmux-zellij`

`tmux-zellij` now forwards to the ghostty launcher so older references keep working.
